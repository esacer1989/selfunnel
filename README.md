# Selfunnel

**Открытый туннельный клиент для NAT и серых IP-адресов.**

Установка в одну команду (Linux / macOS):

```bash
curl -sSL https://selfunnel.ru/install.sh | sh
```

Для Windows:

```powershell
irm https://selfunnel.ru/install.ps1 | iex
```

---

## Что это

Selfunnel поднимает защищённый туннель с вашего компьютера на публичный сервер. После установки ваш сервис (веб-сайт, игровой сервер, RDP, SSH) становится доступен из интернета по постоянному адресу — без настройки роутера, без белого IP, без проброса портов.

## Быстрый старт

### 1. Регистрация

Зарегистрируйтесь на [selfunnel.ru](https://selfunnel.ru) и создайте туннель в личном кабинете.

### 2. Установка клиента

**Linux / macOS:**
```bash
curl -sSL https://selfunnel.ru/install.sh | sh
```

**Windows (PowerShell от имени администратора):**
```powershell
irm https://selfunnel.ru/install.ps1 | iex
```

Скрипт автоматически:
- определит вашу ОС и архитектуру
- скачает и установит [frpc](https://github.com/fatedier/frp) (v0.61.1)
- загрузит ваш конфиг туннелей
- запустит сервис и добавит его в автозагрузку

### 3. Готово

Проверьте статус:

```bash
systemctl status selfunnel   # Linux
# или
curl https://ваш-туннель.selfunnel.ru
```

## Использование

### Игровые серверы (Minecraft, Terraria, Valheim...)

```bash
# Minecraft Java Edition — порт 25565
# Создайте туннель типа TCP в личном кабинете:
#   Локальный адрес: 127.0.0.1:25565
#   Тип: TCP

# После установки друзья подключаются по адресу:
#   ваш-туннель.selfunnel.ru:25565
```

### Веб-серверы

```bash
# Локальный веб-сервер на порту 8080
# Создайте туннель типа HTTP в личном кабинете:
#   Локальный адрес: 127.0.0.1:8080
#   Тип: HTTP

# Сайт доступен по адресу:
#   https://ваш-туннель.selfunnel.ru
```

### Управление

```bash
# Linux
systemctl restart selfunnel   # перезапустить
journalctl -u selfunnel -f    # логи

# Конфиг
cat /opt/selfunnel/frpc.toml
```

## Тарифы

| Тариф | TCP/UDP лимиты | Цена |
|-------|---------------|------|
| Lite  | 300 ГБ/мес   | бесплатно |
| Pro   | 300 ГБ/мес   | от 99 ₽/мес |
| Business | 1 ТБ/мес   | от 299 ₽/мес |

HTTP/HTTPS туннели — безлимитно на всех тарифах.

## Системные требования

- Linux (amd64 / arm64 / arm) или macOS или Windows
- Права root / администратора
- Доступ к интернету (исходящий TCP на порты 7000, 20128)

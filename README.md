# Selfunnel — туннель для игровых серверов за одну команду

Репозиторий с официальными установочными скриптами клиента [selfunnel.ru](https://selfunnel.ru) — сервиса, который открывает доступ к вашему домашнему серверу из интернета без белого IP.

## Зачем это нужно

У большинства домашних подключений в РФ серый IP (CGNAT) — до вашего компьютера нельзя достучаться из интернета. Из-за этого нельзя:

- поднять Minecraft/Terraria сервер для друзей
- получить доступ к домашнему ПК через RDP
- показать локальный веб-проект заказчику
- подключиться к камере/NAS из отпуска

Selfunnel решает это туннелем: небольшая программа на вашем ПК держит соединение с нашим сервером и пробрасывает нужные порты наружу по постоянному адресу.

## Установка

### Linux / macOS

```bash
curl -sSL https://selfunnel.ru/install.sh | sh
```

### Windows (PowerShell от администратора)

```powershell
irm https://selfunnel.ru/install.ps1 | iex
```

Скрипт сам скачает frpc, получит ваш конфиг и зарегистрирует службу.

### Docker

```bash
curl -sSL https://selfunnel.ru/install-docker.sh | sh
```

## Как играть с друзьями в Minecraft

1. Зарегистрируйтесь на [selfunnel.ru](https://selfunnel.ru)
2. Создайте туннель: локальный адрес `127.0.0.1:25565`, тип TCP
3. Установите клиент одной командой (см. выше)
4. Друзья добавляют сервер `ваш-туннель.selfunnel.ru` в клиенте Minecraft

Всё — можно играть.

## Что внутри

- **frpc** (fatedier/frp v0.61.1) — проверенный open-source клиент туннелей
- **systemd-юнит** — автозапуск и автоперезапуск при падении
- **Автоконфиг** — адреса ваших туннелей подтягиваются по токену из личного кабинета

## Управление

```bash
systemctl status selfunnel    # статус
journalctl -u selfunnel -f    # логи в реальном времени
systemctl restart selfunnel   # перезапуск
```
